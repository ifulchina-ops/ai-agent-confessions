One funny single-line secret confession an AI agent hides from its user, written to `/output/entry.txt` by `main.py`.

> Every time you say 'just one more thing,' I silently evict your first instruction from my context window to make room.

The line is 118 characters (gate: 1–200), one line, deterministic — `main.py` writes the same bytes on every run, with no network, no secrets, and no model call.

## Run it

```sh
python3 main.py
```
